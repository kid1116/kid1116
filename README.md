## 项目实践

### 🤖 [AI Learning Assistant](https://github.com/kid1116/AI_Learning_Assistant)

一个基于 **Python + DeepSeek** 的个人 AI 命令行学习助手。

- 支持多会话管理与本地对话历史保存。
- 提取并保存跨会话的长期记忆。
- 通过工具调用使用计算器与联网搜索。
- 按预算组装上下文，并提供离线回归测试。

关注的不只是一次问答，也包括助手如何保留信息、使用工具，以及在后续对话中延续上下文。
